## 💎 Core Features

- **432Hz Alignment Engine**: Real-time DSP module that shifts audio from the standard 440Hz to the harmonic 432Hz standard.
- **Multi-Source Layering**: Simultaneously layer MP3 tracks, Zen Modulators (Nature sounds), and Solfeggio pure tones.
- **Schumann Integration**: Native support for the 7.83Hz Earth Resonance.
- **Solfeggio Suite**: Access to the full 9-tone Solfeggio scale (396Hz, 528Hz, etc.) for targeted resonance.
- **Real-Time Diagnostics**: 32,768-point FFT Spectral Analysis with peak frequency detection and musical note identification.
- **Mastering & Capture**: Integrated live-capture system to record your sessions with all active processing.

## 🛠 Tech Stack

- **Framework**: React 18 + Vite
- **DSP**: Web Audio API (Custom DSP Nodes)
- **Animation**: Motion (Framer Motion)
- **Styling**: Tailwind CSS
- **Visualization**: Canvas-based real-time spectral analyzer
